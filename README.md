# Караоке

Самостоятельный караоке-сервис: загружаете минусовку или песню с голосом — приложение само отделяет голос, выставляет ноты и распознаёт текст, а потом показывает караоке с подсветкой по слогам, синхронизированной со звуком и клипом.

## Как это работает

Загруженный файл проходит конвейер обработки (`backend/pipeline.py`):

1. **Клип** — если это видео, дорожка пережимается в формат, который браузер играет без перекодирования (H.264/AV1 → mp4, VP8/VP9 → webm).
2. **Отделение голоса** — [Demucs](https://github.com/adefossez/demucs) (`htdemucs`) разделяет запись на минус и голос.
3. **Ноты** — [CREPE](https://github.com/marl/crepe) (`torchcrepe`) определяет высоту голоса покадрово (10 мс), из неё собираются ноты.
4. **Текст** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) распознаёт слова и раскладывает их по строкам с таймкодами.

Результат: минус в любой тональности (сдвиг до ±6 полутонов), дорожка голоса, текст с посегментной подсветкой, редактор текста с повторным распознаванием фрагментов. Загруженные клипы можно синхронизировать с минусом вручную.

## Требования

- **Python 3.12** и [uv](https://docs.astral.sh/uv/) — для бэкенда
- **Node.js с npm** — для сборки фронтенда
- **ffmpeg** — в системном PATH, нужен для декодирования аудио и пережатия клипов (на macOS: `brew install ffmpeg`)

Стек: FastAPI + uvicorn на бэкенде; React 19, TypeScript, Vite, Tailwind и zustand на фронтенде.

## Запуск

```bash
./run.sh
```

Скрипт сам создаёт `.venv`, ставит зависимости, собирает фронтенд (только если исходники новее сборки) и поднимает сервер на **http://localhost:8765**.

> Первый запуск скачает большие веса моделей: PyTorch (несколько GB), Demucs и Whisper — через кэш Hugging Face. Это разовая операция.

### Разработка фронтенда

```bash
./run.sh &            # сервер
cd frontend && npm run dev   # vite с горячей перезагрузкой
```

### Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8765` | порт uvicorn |
| `KARAOKE_WHISPER_MODEL` | `medium` | модель Whisper: `small`, `medium`, `large-v3-turbo`, `large-v3` |

## Структура

```
backend/    FastAPI-приложение (app.py) и конвейер обработки (pipeline.py)
frontend/   React + Vite (исходники и сборка dist/)
data/       песни пользователя — не публикуется, переносится отдельно
run.sh      запуск одной командой
```

Песни хранятся в `data/songs/<id>/`: исходник, `meta.json`, минус и голос, `notes.json`, `lyrics.json`, пережатый клип. `data/` намеренно исключена из репозитория — это личный контент.
